# Agent Instructions

## UI and Design System Rules

Before modifying UI:

1. Read `docs/STYLE_GUIDE.md`.
2. Reuse existing design tokens and components.
3. Preserve Space Grotesk for primary text and Inconsolata for technical text.
4. Maintain the Ember Void color tokens.
5. Prefer semantic HTML and minimal component-scoped CSS.
6. Avoid unnecessary dependencies and visual complexity.
7. Preserve accessibility and responsive behavior.
8. Update `docs/STYLE_GUIDE.md` when the design system changes.
